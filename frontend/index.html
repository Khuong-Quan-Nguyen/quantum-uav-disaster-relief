Illustrative scenario: 2 UAVs dispatched from staging points to restore connectivity across 3 flood-prone central Vietnamese provinces. Distances are real great-circle calculations from approximate coordinates — no live disaster or sensor data is used. QAOA is solved on a simulated quantum device (PennyLane lightning.qubit); at this problem size it's expected to match, not beat, the classical brute-force optimum — see the project README for details.
